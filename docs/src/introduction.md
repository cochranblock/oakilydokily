# oakilydokily

Waiver management system with ESIGN support. First paid CochranBlock partnership.

Built on Axum (Rust), oakilydokily provides ESIGN-compliant liability waivers for veterinary professional services. It supports multi-provider OAuth (Google, Facebook, Apple), runs as a single zero-cloud binary, and exposes AI sprite generation via the pixel-forge bridge on KOVA GPU nodes.
